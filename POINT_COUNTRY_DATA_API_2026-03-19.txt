POINT BACKEND - COUNTRY DATA AVAILABILITY
Date: 2026-03-19
Repo: cc-app-backend-v2-monolitic

Contexte du blocage
- GET /admin/country-config/unconfigured-countries renvoyait vide.
- GET /admin/lookups/countries renvoyait vide.
- Le frontend affichait "No countries available".

Objectif
- Rendre la sélection pays opérationnelle en corrigeant uniquement la disponibilité des données et le wiring backend.
- Sans refonte frontend et sans refactor global.

Correctifs implémentés

1) Seed/Fallback master countries
- Fichier: src/main/java/com/ccapp/country/config/service/CountrySetupBootstrapService.java
- Ajout/renforcement de la logique idempotente pour garantir les pays opérationnels:
  BJ, CI, SN, GH, TG (actifs).
- Extension du SAFE fallback pour inclure TG.
- Si la table countries est vide:
  - seed automatique,
  - puis vérification/garantie des pays opérationnels.
- Protection runtime:
  - si, après fallback, aucun pays actif n’est disponible -> BusinessException("No active countries available").

2) Startup seed trigger
- Fichier: src/main/java/com/ccapp/country/config/service/CountryMasterDataBootstrapInitializer.java
- Ajout d’un ApplicationRunner qui déclenche au démarrage:
  - ensureMasterCountriesSeededIfEmpty()
  - et un check configured/unconfigured avec logs.

3) Migration Flyway idempotente
- Fichier: src/main/resources/db/migration/V43__ensure_operational_countries.sql
- Upsert idempotent de BJ/CI/SN/GH/TG.
- Force active=true et status='ACTIVE' sur ces pays.

4) Lookup API corrigée
- Fichier: src/main/java/com/ccapp/admin/service/AdminLookupService.java
- GET /admin/lookups/countries sert maintenant les pays actifs uniquement.
- Ajout du fallback seed avant lecture.
- Ajout des logs de comptage:
  - totalCountriesInDb
  - activeCountriesCount
  - configuredCountriesCount
  - unconfiguredCountriesCount
- Si aucun pays actif: BusinessException explicite (pas de vide silencieux).

5) Unconfigured logic alignée
- Fichier: src/main/java/com/ccapp/country/config/service/CountrySetupBootstrapService.java
- Logique confirmée:
  unconfigured = countries active MINUS distinct country_code de country_config_versions.
- Normalisation des country codes (trim + uppercase) pour éviter les faux négatifs.

6) Transaction de workspace
- Fichier: src/main/java/com/ccapp/admin/service/AdminCountryWorkspaceService.java
- Retrait du readOnly sur les méthodes d’overview/detail pour ne pas bloquer un fallback seed si nécessaire.

7) Test d’intégration ajusté
- Fichier: src/test/java/com/ccapp/country/config/service/CountrySetupBootstrapServiceIntegrationTest.java
- Adaptation des tests pour le nouveau comportement bootstrap (pays cœur garantis).
- Résultat test ciblé:
  - Commande: mvn -Dtest=CountrySetupBootstrapServiceIntegrationTest test
  - Statut: BUILD SUCCESS
  - Tests run: 5, Failures: 0, Errors: 0
