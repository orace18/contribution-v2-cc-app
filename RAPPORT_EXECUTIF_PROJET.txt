RAPPORT EXECUTIF - ETAT GLOBAL DU PROJET
Date: 2026-03-07

1) Architecture
- Backend Spring Boot monolithe modulaire en place.
- Modules actifs: identity, payments, ledger, circles, circlesocial, progress, credit, agent, capital.

2) Refactors majeurs livres
- Refonte identity en modele delegue:
  AccountHolder (personne), AppUser (utilisateur app), Wallet, AccountDelegation.
- Securite/auth mise a jour avec accountHolderId + actorUserId.
- Migration progressive de userId vers accountHolderId dans les flux metier cles.

3) Fonctionnalites metier livrees
- circles: creation, adhesion, mon cercle, membres, regles (max 5 membres, 1 cercle actif/utilisateur).
- circlesocial: activite, progression, score cercle.
- progress: taches utilisateur + recalcul automatique de progression.
- payments + psp + ledger: souscriptions, callbacks PSP, ecritures comptables, reconciliation.
- credit: eligibilite, prets, echeancier, remboursements, ecritures ledger pret.
- agent: acces assiste/offline, sessions d'assistance auditees, transactions offline + synchronisation.
- capital: fonds, pools de capital, financement de pret.

4) Regles cles appliquees
- Toute action sensible trace actorUserId et accountHolderId.
- Un pret doit etre finance par un capital_pool avant decaissement.
- Le remboursement met a jour l'echeancier.
- Le decaissement/remboursement declenche des ecritures comptables (ledger).
- Les sessions assistees sont journalisees pour audit.

5) Base de donnees
- Migrations presentes: V1 a V11, puis V13.
- Nouvelles couches ajoutees:
  V9 (identity refactor), V10 (loan engine), V11 (agent/offline), V13 (capital engine).

6) Qualite / validation
- Build OK.
- Tests OK (mvn test passe).

7) Point d'attention
- Numerotation Flyway: V12 absente (a traiter si vous voulez une sequence strictement continue).
