POINT DE SITUATION — Country Setup Bootstrap / Lookup / Onboarding
Date: 2026-03-18

Périmètre appliqué
- Aucun refactor global du config engine.
- Corrections ciblées sur bootstrap, lookup, onboarding (backend + backoffice).

1) Backend — Correctifs livrés

1.1 Endpoints Country Setup
- GET /admin/country-config/configured-countries
- GET /admin/country-config/unconfigured-countries
- POST /admin/country-config/{countryCode}/initialize (conservé + logging tentative)
- GET /admin/lookups/countries (vérifié + bootstrap safe seed déclenché si master vide)

1.2 Logique configured / unconfigured
- configured = pays actifs du master ayant déjà des versions en country_config_versions.
- unconfigured = pays actifs du master sans initialisation de configuration.
- Format retour: { code, name, configured }.

1.3 Bootstrap seed safe
- Si la table master countries est vide: seed idempotent de base:
  BJ, CI, GH, SN, INT.
- Objectif: débloquer immédiatement le démarrage du Country Setup.

1.4 Logging ajouté
- total master countries
- configured countries count
- unconfigured countries count
- initialize attempts

2) Backoffice — Correctifs livrés

2.1 Sources des sélecteurs
- “Configured country” alimenté par /configured-countries.
- “Create new country configuration” alimenté par /unconfigured-countries.

2.2 États UX onboarding/diagnostic
- Si configured = 0 et unconfigured > 0:
  “No country configured yet. Start by creating your first country configuration.”
- Si configured = 0 et unconfigured = 0:
  “No countries available. Please seed or activate country master data.”
- Plus d’affichage de selects vides sans explication.

3) Tests et validation

3.1 Tests backend ajoutés
- master countries existent, none configured
- some configured, some unconfigured
- no master countries
- initialize déplace un pays de unconfigured vers configured

3.2 Exécutions réalisées
- Backend tests ciblés: PASS
  mvn -q -Dtest=CountrySetupBootstrapServiceIntegrationTest,CountryConfigurationEngineServiceIntegrationTest,CountryConfigResolverIntegrationTest test
- Build backoffice: PASS
  npm run -s build

4) Résultat

- Le bootstrap Country Setup est débloqué.
- Les listes configured/unconfigured sont cohérentes et exploitables.
- L’onboarding est explicite en cas d’absence de configuration.
- Le comportement est couvert par tests sans régression détectée sur les suites ciblées.
