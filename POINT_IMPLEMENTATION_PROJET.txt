1) PHOTO GLOBALE DU PROJET
====================================================================

2) SECURITE ET AUTHENTIFICATION IMPLEMENTEES
====================================================================
- Securite stateless (Spring Security) avec filtres:
  - Auth admin JWT pour /api/admin/**
  - API key interne (X-API-KEY) pour /internal/**
  - Auth Firebase ID token pour les endpoints users
- Endpoints publics autorises:
  - /actuator/health
  - /actuator/info
  - /public/countries
  - /public/activity-sectors
  - /public/income-brackets
  - /psp/jawupay/callback (POST)

- CORS configurable via app.cors.allowed-origins.
- Validation des secrets obligatoires au demarrage (RequiredSecretsValidator).

====================================================================
9) PAYMENTS / SUBSCRIPTION / PSP
====================================================================
Subscription:
- Liste plans par service country.
- Initiation abonnement:
  - creation operation INITIATED (idempotency key)
  - appel client Jawupay
  - affectation pspReference

PSP callback Jawupay:
- Endpoint public /psp/jawupay/callback
- Verifications:
  - rate limiting IP
  - replay protection (nonce + fenetre timestamp)
  - signature HMAC
- Si callback SUCCESS/CONFIRMED:
  - confirmation operation
  - posting comptable
  - calcul commissions MLM subscription

Important:
- JawupayClientImpl actuel est un adaptateur mock (genere pspReference/checkoutUrl de test).
